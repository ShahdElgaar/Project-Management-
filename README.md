# Data Analysis Project Management

This repository demonstrates a data analysis project planned and tracked using both ProjectLibre and Jira. 

## Tools Used
- **ProjectLibre**: Detailed planning, Gantt charts, subtasks, and dependencies.

- **Jira**: Task tracking, workflow management, assignees, and progress monitoring.

## Files
- ProjectLibre.pod → Full project plan with timeline and dependencies.
  
- Jira.csv → Export of tasks, subtasks, assignees, and start/due dates.
